# Investment Advisory Platform — BA & Data Analysis Project

> **Business Analysis portfolio** simulating the full lifecycle of designing a Stock Investment Advisory Platform — from requirements gathering to process modeling and data-driven stock screening.

## About This Project

This project demonstrates core **Business Analyst skills** applied to a real-world domain I know deeply: stock investment advisory. Having worked as a freelance investment analyst for 2+ years, I bring both domain knowledge and structured BA methodology to design a platform that helps investors screen, analyze, and track high-growth stocks.
